Laravel Auth Kit

Package Laravel plug-and-play pour les projets API. Installez-le et tout est prêt : authentification Sanctum, profil, reset OTP, rôles Spatie et logs d'activité complets.

Laravel 10/11/12 Sanctum Spatie Permissions OTP Email Activity Logs PHP 8.1+

✦ Fonctionnalités

🔐
Authentification Sanctum
Login, logout multi-mode, /me, liste des sessions actives avec révocation ciblée
👤
Gestion de profil
Prénom, nom, email, téléphone. Champs configurables. Statut non modifiable par l'utilisateur.
📧
Reset mot de passe OTP
Flux 3 étapes : email → code OTP 6 chiffres → reset_token → nouveau mot de passe
🛡️
Rôles & Permissions
CRUD complet via Spatie Laravel Permission. Assignation rôle↔permission et utilisateur↔rôle.
📊
Logs d'activité
IP réelle, appareil, OS, navigateur, géolocalisation GPS, action CRUD et ressource cible.
🏢
Mode Admin
Création de comptes par admin avec mot de passe temporaire. Statut active/inactive/banned.

⚡ Installation

Installer via Composer
bash
composer require s3tech/laravel-auth-kit
Publier les fichiers
bash
# Config
php artisan vendor:publish --tag=auth-kit-config

# Sanctum
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"

# Spatie
php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"

# Auth Kit migrations
php artisan vendor:publish --tag=auth-kit-migrations

# (Optionnel) User model stub
php artisan vendor:publish --tag=auth-kit-user-model
Migrer
bash
php artisan migrate
✓Toutes les tables sont créées : users, auth_kit_activity_logs, auth_kit_password_reset_otps, tables Spatie et Sanctum.
Configurer le modèle User
php · app/Models/User.php
use Laravel\Sanctum\HasApiTokens;
use Spatie\Permission\Traits\HasRoles;
use S3Tech\AuthKit\Traits\HasAuthKit;

class User extends Authenticatable
{
    use HasApiTokens, HasRoles, HasAuthKit;

    protected $fillable = [
        'first_name', 'last_name', 'email',
        'phone', 'password', 'must_change_password', 'status',
    ];
    protected $hidden = ['password', 'remember_token'];
    protected $casts  = [
        'email_verified_at'   => 'datetime',
        'must_change_password' => 'boolean',
    ];
}
Guard Spatie = sanctum
php · config/permission.php
'guard_name' => 'sanctum',

🌱 Seeder de rôles initiaux

À exécuter une seule fois pour initialiser les rôles et permissions de base.

php · database/seeders/RoleSeeder.php
use Spatie\Permission\Models\Role;
use Spatie\Permission\Models\Permission;

Role::firstOrCreate(['name' => 'super-admin', 'guard_name' => 'sanctum']);
Role::firstOrCreate(['name' => 'manager',     'guard_name' => 'sanctum']);
Role::firstOrCreate(['name' => 'user',        'guard_name' => 'sanctum']);

$permissions = ['manage-roles', 'create-user', 'update-user'];
foreach ($permissions as $perm) {
    Permission::firstOrCreate(['name' => $perm, 'guard_name' => 'sanctum']);
}
Role::findByName('super-admin', 'sanctum')->givePermissionTo($permissions);

⚙ Configuration

Après vendor:publish, le fichier config/auth-kit.php est disponible.

php · config/auth-kit.php
return [
    'route_prefix'     => 'api',
    'route_middleware' => ['api'],
    'user_model'       => \App\Models\User::class,
    'registration'     => ['mode' => 'self', 'default_role' => 'user'],
    'profile'          => ['editable_fields' => ['first_name','last_name','email','phone']],
    'otp'              => ['length' => 6, 'expires_in' => 10],
    'password_rules'   => ['min:8'],
    'activity_log'     => [
        'enabled'        => true,
        'retention_days' => 90,
        'log_events'     => [ /* tous à true par défaut */ ],
    ],
    'permissions' => [
        'manage_roles'      => 'manage-roles',
        'create_user'       => 'create-user',
        'update_other_user' => 'update-user',
    ],
];

🔑 Flux Reset OTP

Processus en 3 étapes pour réinitialiser un mot de passe oublié.

POST /api/auth/forgot-password
{ "email": "user@example.com" }
// 200 → OTP envoyé par email
POST /api/auth/verify-otp
{ "email": "user@example.com", "otp": "482910" }
// 200 → { "reset_token": "a1b2c3..." }
POST /api/auth/reset-password
{
  "email":                 "user@example.com",
  "reset_token":           "a1b2c3...",
  "password":              "NewPass123",
  "password_confirmation": "NewPass123"
}
// 200 — tous les tokens révoqués

👥 Modes d'inscription

Mode self

L'utilisateur s'inscrit via POST /api/auth/register avec son propre mot de passe. Route publique.

config
'mode' => 'self'

Mode admin

Route /register désactivée. Un admin (create-user) crée les comptes. Mot de passe temporaire envoyé par email.

config
'mode' => 'admin'

🚪 Modes de déconnexion

POST /api/auth/logout
// Session courante (défaut)
{ "mode": "current" }

// Session précise (ID via GET /auth/sessions)
{ "mode": "specific", "token_id": 12 }

// Toutes les sessions
{ "mode": "all" }

🚦 Statut des comptes

StatutLoginDescription
active✅Compte normal, accès complet
inactive❌ 403Compte désactivé temporairement
